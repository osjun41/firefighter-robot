Only the `policy/` package of the upstream lowlevel repo (`RlController`, `Cfg`, `Se2Gamepad`), used by the MuJoCo sim2sim scripts and `berkeley_humanoid_lite/environments/mujoco.py`. Hardware drivers of the robot live in `legs/` and `actuators/`. See `sim/locomotion/UPSTREAM.md`.
